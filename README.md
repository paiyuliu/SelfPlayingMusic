# SelfPlayingMusic 自彈自唱

> 給不擅長樂器與樂理的人，藉由 AI 輔助開發的傻瓜伴奏系統。

純 HTML + JavaScript，無需安裝任何環境，可直接部署於 GitHub Pages。

## 目前功能（目標 1）

### 和弦觸發

按下一個鍵，自動演奏完整一小節（4 拍）的和弦：

| 和弦類型 | 說明 |
|----------|------|
| 大三和弦 | 四拍同時按住根音、大三度、完全五度 |
| 小三和弦 | 四拍同時按住根音、小三度、完全五度 |
| 根音＋和弦 | 第 1 拍根音，第 2–4 拍和弦各觸發一下（恰恰恰）|
| 琶音 | 根音→三度→五度→三度，每拍一音 |

### 輸入方式

- **MIDI 鍵盤**：按任意鍵，以該音為根音觸發和弦（需瀏覽器支援 Web MIDI API）
- **電腦鍵盤**：`C` `D` `E` `F` `G` `A` `B` 對應 C4–B4 各音
- **滑鼠**：點擊畫面上的虛擬琴鍵

### BPM 控制

- 大數字上滾動滑鼠滾輪
- 拖拉滑桿
- 點擊 `−` / `+` 按鈕（每次 ±5）
- 直接在輸入框鍵入數字
- 頁面上按鍵盤 `↑` `↓`（每次 ±1）

### 其他

- **音色**：鋼琴 / 管風琴 切換
- **節拍器**：可開關聲音，使用 Tone.js 精準計時
- **節拍視覺**：4 個圓點逐拍閃爍

## 本地執行

直接用瀏覽器開啟 `index.html` 即可，無需伺服器。

> MIDI 鍵盤需使用支援 Web MIDI API 的瀏覽器（建議 Chrome / Edge）。
